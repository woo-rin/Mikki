# Mikki

AI가 써낸 가짜 뉴스를 읽고 가상 주식시장에 투자하는 게임. **뉴스 중 일부는 미끼다.**

호재처럼 읽히는 기사가 실제로는 주가를 끌어내리고, 그럴듯한 계약 소식이 이미 반영된
내용의 재인용일 수 있다. 판별할 방법은 하나뿐 — 라운드당 **5회 제한의 `AI 분석`** 이다.
분석은 확실한 답을 주지만, 기다리는 몇 초 동안에도 시장은 계속 움직인다.

파산하면 `노가다` 버튼이 열린다. 2분간 아무것도 못 하는 대신 현금을 받지만,
보수는 회차마다 3/5로 줄어든다.

## 빠른 시작

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./run.sh                       # http://localhost:7999
```

`ANTHROPIC_API_KEY` 가 있으면 뉴스와 해설을 Claude 가 쓰고, 없으면 로컬 템플릿으로
돌아간다. **어느 쪽이든 게임은 멈추지 않는다.**

### 테스트

```bash
cd backend
.venv/bin/pytest -q            # 122 passed
```

전부 API 키 없이 통과한다. 테스트는 Claude 를 한 번도 부르지 않는다.

### 손으로 한 판

```bash
SID=$(curl -s -X POST localhost:7999/api/game | python3 -c 'import json,sys; print(json.load(sys.stdin)["session_id"])')
curl -s "localhost:7999/api/state?session_id=$SID" | python3 -m json.tool
```

뉴스는 12~18초 간격으로 등장하므로 시작 직후에는 피드가 비어 있는 것이 정상이다.

## 구조

```
backend/          FastAPI 서버 — 이 안에서 자족한다
  app/            9개 모듈 (아래)
  tests/          7개 파일, 122개 테스트
  run.sh          포트 7999 로 고정 실행
design/           UI 목업 아트보드 (.dc.html)
docs/
  api.md          API 명세 — 1부 현행 계약, 2부 v2 설계
  superpowers/    설계 스펙과 구현 계획
```

| 모듈 | 하는 일 |
|---|---|
| `config` | 모든 밸런스 수치 |
| `scenario` | 낚시 뉴스 설계 — 임팩트·램프·등장 시각을 미리 확정 |
| `engine` | 가격 시뮬레이션 — 랜덤워크 + 뉴스 램프 |
| `session` | 거래·수수료·파산·노가다·라운드 |
| `fallback` | Claude 없이 뉴스와 해설 생성 |
| `news` / `analysis` | Claude 를 아는 유일한 두 파일 |
| `main` | HTTP, 세션 저장소, 동시성 |

## 설계에서 중요한 것

**정답은 서버 밖으로 나가지 않는다.** 각 기사의 실제 임팩트는 어떤 응답에도 없다.
분석을 지불해야만 등급을 얻는다.

**뉴스 생성과 분석은 정반대로 작동한다.** 기사를 쓸 때 Claude 는 표면 톤만 받는다 —
실제 임팩트를 알면 함정 기사에 무의식적으로 유보적 표현을 흘려, 플레이어가 읽기만으로
알아채기 때문이다. 분석할 때는 반대로 확정된 판정을 전부 넘기고 근거만 설명하게 한다.

**서버에 타이머가 없다.** 시장은 상태 조회 요청이 도착할 때 그만큼 진행된다.
그래서 폴링 간격이 결과를 바꾸지 않고, 탭을 비웠다 돌아오면 밀린 시간이 한꺼번에 흐른다.

## 현재 상태

- **백엔드** — 완료. 7개 기능, 122개 테스트.
- **프론트엔드** — 미착수. 목업 3안이 `design/` 에 있고 방향은 미선택.
- **v2 설계** — AI 참가자와의 경주, 거래량, 현금 기준 목표. 설계만 되어 있고 코드는 없다.
  자세한 내용은 [`docs/api.md`](docs/api.md) 2부.

## 문서

**[`docs/api.md`](docs/api.md)** 가 프론트 작업의 출발점이다. 실제 서버 응답을 캡처해
작성했고, API 가 주지 않아 프론트가 직접 계산해야 하는 것들을 따로 정리해 두었다.
