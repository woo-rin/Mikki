# Mikki

AI가 써낸 가짜 뉴스를 읽고 가상 주식시장에 투자하는 게임. **뉴스 중 일부는 미끼다.**

호재처럼 읽히는 기사가 실제로는 주가를 끌어내리고, 그럴듯한 계약 소식이 이미 반영된
내용의 재인용일 수 있다. 판별할 방법은 하나뿐 — 라운드당 **5회 제한의 `AI 분석`** 이다.
분석은 확실한 답을 주지만, 기다리는 몇 초 동안에도 시장은 계속 움직인다.

그리고 기사가 진짜여도 이기는 것은 아니다. 각 종목에는 **실제 기업의 재무에서 낸
적정가**가 있고 가격은 거기로 서서히 끌린다. 호재가 진짜였어도 고평가 종목이면 램프가
끝나는 순간 앵커가 끌어내린다. 적정가를 보려면 **라운드당 2회의 `기업분석`** 을 써야 한다.

**한 판은 10분짜리 경주다.** 마감에 닿거나, 그 전에 누가 **현금 목표(시드의 3배)를
먼저 확정하면** 경주가 끝난다. 전원의 주식이 강제
매도되고 최종 현금으로 순위가 매겨진다. 그래서 사서 오르기만 해서는 못 이긴다 —
언제 파느냐가 실력이다.

노가다 버튼은 언제든 열려 있다. 2분간 아무것도 못 하는 대신 현금을 받지만,
보수는 회차마다 3/5로 줄어든다.

## 빠른 시작

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./run.sh                       # http://localhost:7999
```

`ANTHROPIC_API_KEY` 가 있으면 뉴스와 해설을 Claude 가 쓰고, 없으면 로컬 템플릿으로
돌아간다. **어느 쪽이든 게임은 멈추지 않는다.**

### 테스트

```bash
cd backend
.venv/bin/pytest -q            # 359 passed
```

전부 API 키 없이 통과한다. 테스트는 Claude 를 한 번도 부르지 않는다.

### 손으로 한 판

```bash
SID=$(curl -s -X POST localhost:7999/api/game | python3 -c 'import json,sys; print(json.load(sys.stdin)["session_id"])')
curl -s "localhost:7999/api/state?session_id=$SID" | python3 -m json.tool
```

뉴스는 약 30초 간격으로 등장하므로 시작 직후에는 피드가 비어 있는 것이 정상이다.
시세는 5초에 한 번 갱신된다.

## 구조

```
backend/          FastAPI 서버 — 이 안에서 자족한다
  app/            13개 모듈 (아래)
  data/           재무 스냅샷 — 커밋된다
  scripts/        DART 갱신 스크립트 — 서버는 임포트하지 않는다
  tests/          11개 파일, 359개 테스트
  run.sh          포트 7999 로 고정 실행
design/           UI 목업 아트보드 (.dc.html)
docs/
  api.md          API 명세 — 1부 현행 계약, 2부 v2 설계
  superpowers/    설계 스펙과 구현 계획
```

| 모듈 | 하는 일 |
|---|---|
| `config` | 모든 밸런스 수치 |
| `scenario` | 낚시 뉴스 설계 — 임팩트·램프·등장 시각을 미리 확정 |
| `engine` | 가격 시뮬레이션 — 랜덤워크 + 뉴스 램프 + 적정가 앵커 + 주문 흐름 |
| `session` | 거래·수수료·파산·노가다·라운드·체결 피드 |
| `participants` | AI 참가자 9명 — 결정론적 매매 정책 |
| `board` | 종토방 — AI 가 기사에 한마디 단다 |
| `fundamentals` | 재무 스냅샷 → 적정가와 밸류에이션 등급 |
| `fallback` | Claude 없이 뉴스와 해설 생성 |
| `news` / `analysis` / `company_analysis` / `board` | Claude 를 아는 네 파일 |
| `main` | HTTP, 세션 저장소, 동시성 |

## 설계에서 중요한 것

**정답은 서버 밖으로 나가지 않는다.** 각 기사의 실제 임팩트는 어떤 응답에도 없다.
분석을 지불해야만 등급을 얻는다.

**뉴스 생성과 분석은 정반대로 작동한다.** 기사를 쓸 때 Claude 는 표면 톤만 받는다 —
실제 임팩트를 알면 함정 기사에 무의식적으로 유보적 표현을 흘려, 플레이어가 읽기만으로
알아채기 때문이다. 분석할 때는 반대로 확정된 판정을 전부 넘기고 근거만 설명하게 한다.

**서버에 타이머가 없다.** 시장은 상태 조회 요청이 도착할 때 그만큼 진행된다.
그래서 폴링 간격이 결과를 바꾸지 않고, 탭을 비웠다 돌아오면 밀린 시간이 한꺼번에 흐른다.

**재무는 진짜, 이름은 가상이다.** 실존 기업의 매출·영업이익·순이익을 그대로 쓰되 종목명은
가상으로 둔다. 실명을 쓰면 역방향 함정 기사가 **실존 기업에 대한 허위 악재**가 되고,
스크린샷 한 장이 게임 밖으로 나가면 맥락이 사라진다.

**시작가가 매판 다르다.** 각 종목은 적정가 대비 ±30% 사이 랜덤 위치에서 출발한다. 고정
시작가면 어느 종목이 고평가인지가 매판 같아서, 한 번 외운 플레이어에게 기업분석이 죽는다.

**AI 는 LLM 이 아니다.** 탭을 30분 비웠다 돌아오면 1,800 tick 이 한 요청에서 진행되고 AI
매매도 그 안에서 재생된다. LLM 호출은 재생이 안 되고 1,800번 부를 수도 없다. AI 는
(시드, tick, 뉴스)의 **결정론적 함수**다.

**누가 들어갔는지가 단서다.** 체결 피드에 전원의 매매가 흐른다. 김부장이 매번 낚이는
성향이라면, 어떤 기사에 **김부장만** 들어간 것은 함정의 신호다. 숫자가 아니라 신원을
읽는 것이다.

## 현재 상태

- **백엔드** — 359개 테스트. **v2 가 전부 들어갔다** — AI 참가자와의 경주, 현금 기준
  목표, 게임 종료와 최종 순위까지.
- **재무 데이터** — `backend/data/fundamentals.json` 은 아직 **임시 스냅샷**이다.
  적정가가 기존 시작가와 0.1% 이내로 맞도록 맞춰 둔 기준선이다. 실제 DART 데이터로
  바꾸려면 `DART_API_KEY` 를 발급받고 `scripts/fetch_fundamentals.py` 의 `MAPPING` 에
  실존 `corp_code` 를 채운 뒤 돌린다.
- **프론트엔드** — 미착수. 목업 3안이 `design/` 에 있고 방향은 미선택.
- **프론트** — 201개 테스트. 경주 계약과 종토방까지 따라왔다.
- **남은 것** — `backend/data/fundamentals.json` 이 아직 임시 스냅샷이다.
  `DART_API_KEY` 를 발급받아 `scripts/fetch_fundamentals.py` 를 돌리면 실제
  기업 재무로 바뀐다.
