# 경주 (D·E) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 목표를 현금으로 바꾸고, 누구든 먼저 닿으면 게임이 끝나 최종 순위가 나오게 한다.

**Architecture:** 라운드를 없애고 한 판을 한 경주로 만든다. 목표 도달은 tick 루프 안에서 검사하고, 닿는 순간 전원의 주식을 강제 매도해 최종 현금으로 줄 세운다. 승자는 **강제 매도 전에** 확정하므로 승자의 최종 현금이 2위보다 적을 수 있다.

**Tech Stack:** Python 3.11, FastAPI 0.115.6, pytest 8.3.4. 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-09-15-race-design.md`

**범위:** 백엔드만. 프론트는 옆 세션의 종토방이 끝난 뒤 별도 작업이다.

## Global Constraints

- **작업 디렉터리는 언제나 `backend/`** 다.
- **테스트는 네트워크도 Claude 도 부르지 않는다.** 기존 286개가 그렇다.
- `pytest.ini` 가 **경고를 오류로 취급한다.**
- **숫자 리터럴은 `config.py` 에만.**
- **돈은 전부 `math.floor` 내림.**
- **증분 계산과 일괄 계산이 같아야 한다.** 종료 판정이 tick 루프에 들어가므로 특히 조심한다.
- **`round_no` 는 `1` 로 남긴다.** 프론트가 상단바에 쓰고 있고 옆 세션이 프론트를 만지는 중이다. 기한이 있는 임시 호환이다.
- **파산은 총자산 기준을 유지한다.** 목표만 현금으로 바뀐다.
- 매 태스크는 `.venv/bin/pytest -q` **전체**가 통과한 상태로 끝난다.

def quarter_count(symbol: str = "geno") -> int:
    """스냅샷이 들고 있는 분기 수. 판 시작 때 하나를 고르는 데 쓴다."""
    return len(load()["stocks"][symbol]["quarters"])


def quarter_of(snapshot: dict, symbol: str, index: int) -> dict:
    """0-기반 분기. 범위 밖은 있는 것 중 가장 가까운 것으로 붙인다."""
    quarters = snapshot["stocks"][symbol]["quarters"]
    return quarters[max(0, min(index, len(quarters) - 1))]


def fair_values(index: int) -> dict[str, int]:
    """그 분기의 전 종목 적정가."""
    snapshot = load()
    return {
        symbol: fair_value(symbol, quarter_of(snapshot, symbol, index))
        for symbol in config.STOCKS
    }

```python
# --------------------------------------------------------------- 경주 종료

def winner_of(sess: GameSession) -> str | None:
    """목표에 닿은 사람. 아무도 없으면 None.

    같은 tick 에 둘이 넘으면 플레이어가 먼저다 — 임의로 흔들리면 같은 시드가
    다른 결과를 낸다.
    """
    if sess.cash >= sess.target:
        return "you"
    for ai in sess.ais:
        if ai.cash >= sess.target:
            return ai.profile.name
    return None


def _liquidate_player(sess: GameSession) -> None:
    """보유 전량을 현재가로 판다. 잠금을 검사하지 않는다 —
    노가다 중이어도 경주는 끝나고, 잠금은 매매를 막지 청산을 막지 않는다.
    """
    for symbol in list(sess.holdings):
        qty = sess.holdings[symbol]
        gross = engine.price_of(sess.prices, symbol) * qty
        sess.cash += gross - _fee(gross)
    sess.holdings.clear()
    sess.cost_basis.clear()


def finish_race(sess: GameSession, winner: str) -> None:
    """전원 강제 매도 후 순위를 확정한다.

    승자는 **매도 전에** 정해져 있다. 그래서 승자의 최종 현금이 2위보다 적을
    수 있다 — 목표선을 막 넘은 사람과, 주식을 잔뜩 들고 있다가 강제 매도로 큰
    현금을 쥔 사람이 있을 때 그렇다. 의도한 것이다: 목표는 먼저 확정한 사람의
    것이고, 그래서 익절을 미루는 데 대가가 있다.

    수수료도 부과한다 — 미리 팔아둔 사람이 유리해야 익절 판단에 의미가 생긴다.
    """
    _liquidate_player(sess)
    for ai in sess.ais:
        for symbol in list(ai.holdings):
            participants.sell_all(ai, symbol, engine.price_of(sess.prices, symbol))

    rows = [{"name": "나", "cash": sess.cash, "is_player": True}]
    rows += [
        {"name": ai.profile.name, "cash": ai.cash, "is_player": False}
        for ai in sess.ais
    ]

    def is_winner(row: dict) -> bool:
        return row["name"] == winner or (winner == "you" and row["is_player"])

    champion = next(row for row in rows if is_winner(row))
    rest = sorted(
        (row for row in rows if row is not champion),
        key=lambda row: -row["cash"],
    )

    sess.status = "finished"
    sess.winner = winner
    sess.ranking = [
        {**row, "rank": rank}
        for rank, row in enumerate([champion, *rest], start=1)
    ]
```

```python
def _sync(sess: GameSession, now: float) -> int:
    """tick 을 현재까지 진행하고 노가다 보수를 정산한다.

    끝난 경주는 더 이상 흐르지 않는다. 결과가 폴링할 때마다 바뀌면 안 된다.
    """
    if sess.status == "finished":
        return sess.prices.last_tick

    tick = _tick_of(sess, now)

    def on_tick(at: int) -> dict[str, int]:
        return participants.run_tick(
            sess.ais, sess.plans, at, sess.ai_seed,
            lambda symbol: engine.price_of(sess.prices, symbol),
            lambda actor, fill: rules.record_fill(sess, at, actor, fill),
        )

    # AI 의 매도가 목표를 넘기는 순간이 tick 루프 안이다. 매 tick 본다 —
    # 뒤에서 한 번만 보면 따라잡기가 폴링보다 멀리 가서 승자가 달라진다.
    engine.advance(
        sess.prices, sess.plans, tick, sess.rng,
        on_tick=on_tick,
        should_stop=lambda: rules.winner_of(sess) is not None,
    )
    reached = sess.prices.last_tick
    rules.prune_volume(sess, reached)
    rules.settle_grind(sess, now)

    champion = rules.winner_of(sess)
    if champion is not None:
        rules.finish_race(sess, champion)
    return reached
```
