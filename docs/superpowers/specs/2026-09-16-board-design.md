# 종토방 설계

작성일: 2026-09-16 · 대상: 3차 (3단계 중 마지막) · 선행: [AI 참가자](2026-09-14-ai-participants-design.md)

## 1. 무엇을 더하나

받은 피드백 ②가 이것이다. 그리고 게임 설계상으로는 **세 번째 정보 레이어**다.

| 층 | 무엇을 묻나 | 사는 방법 | 믿을 수 있나 |
|---|---|---|---|
| 뉴스 | 이 기사가 진짜인가 | `AI 분석` 5회 | **믿을 수 없는 기사** |
| 펀더멘털 | 이 회사가 애초에 좋은가 | `기업분석` 2회 | 확정된 사실 |
| **종토방** | **다들 어떻게 보나** | **공짜** | **믿을 수 없는 군중** |

체결 피드가 *"누가 들어갔나"* 를 보여준다면, 종토방은 *"왜 들어갔다고 말하는가"* 를 보여준다. 그리고 그 말이 틀릴 수 있다는 것이 요점이다.

## 2. 가장 큰 위험 — 분석을 우회하는 길

AI 는 `view_of` 로 강세/약세를 판단한다. 그 판단이 글에 드러나면 **정소장(통찰력 0.90)의 글은 사실상 정답**이다. 아홉 명의 의견이 공짜로 깔리는 순간 **라운드당 5회의 AI 분석이 무의미해진다.**

1차에서 펀더멘털을 설계할 때와 같은 문제다. 그때의 답은 *"두 축을 직교시킨다"* 였고, 여기서의 답은 **문체를 평평하게 만드는 것**이다.

### 프롬프트에 통찰력을 주지 않는다

Claude 에게 주는 것은 **이름·종목·헤드라인·강세/약세** 뿐이다. 그 AI 가 고수인지 호구인지는 **넘기지 않는다.**

`news.py` 가 `impact` 를 안 주는 것과 **정확히 같은 이유**다. 알면 무의식적으로 문체에 흘리고, 플레이어가 읽기만으로 알아챈다.

### 대신 이름으로 배운다

이름은 고정이다. 몇 판 하다 보면 *"김부장이 들뜨면 함정"* 을 배운다. `api.md` §04 가 체결 피드에 대해 말한 것과 같은 구조다 — **숫자가 아니라 신원을 읽는 것**이고, 판을 거듭하며 쌓이는 지식이다.

> 종토방은 처음엔 소음이고, 판을 거듭하면 신호가 된다.

## 3. 뉴스 배치에 딸린다

AI 의 판단은 `sees_through(ai_seed, ai_index, news_id)` 라 **뉴스가 만들어지는 시점에 이미 결정 가능하다.** tick 에 달린 것은 매매 실행뿐이다.

그래서 글도 그때 같이 만든다.

```
build_plans      각 기사에 대해 누가 말할지 · 뭐라 할지 확정
  ↓
fetch_news       기사 문장            (Claude 1회)
fetch_posts      종토방 글            (Claude 1회)   ← 새로 붙는 단계
```

**따라잡기 때 Claude 호출이 0회다.** 30분 비웠다 돌아와도 글이 그대로 재생된다. 배치 + 폴백이라는 기존 패턴을 그대로 쓴다.

## 4. 누가 말하는가 — 베팅 비율이 곧 수다

전원이 모든 기사에 쓰면 30초마다 아홉 개가 쏟아진다. **뉴스당 최대 4명**으로 끊는다.

발언 확률은 **`bet_ratio` 를 그대로 쓴다.** 몰빵하는 사람이 떠든다 — 실제 종토방이 그렇다. 새 상수를 만들 필요가 없고, 아홉 명의 베팅 비율 합이 3.6 이라 기대 발언자가 저절로 3~4명이 된다.

```
speak = Random(seed).random() < ai.bet_ratio      # 상한 BOARD_MAX_SPEAKERS = 4
```

실제 분포는 4명 52% · 3명 26% · 2명 15% · 1명 5% · **0명 1%** 다. 댓글이 하나도 안 달리는 기사가 가끔 있는 것이 자연스럽다 — 억지로 하한을 두지 않는다.

| | 베팅 | 발언 |
|---|---|---|
| 박선배 | 60% | 자주 |
| 김부장 | 55% | 자주 |
| 강사원 | 50% | 자주 |
| 배차장 | 25% | 드물게 |
| 신주임 | 20% | 드물게 |

**새 파라미터를 만들지 않는다.** 기존 성향에서 성격이 저절로 나오고, 잘 낚이는 쪽(김부장 0.22 · 박선배 0.20)이 시끄러운 것이 **의도한 소음**이다.

발언자 선택은 `Random((ai_seed * 7919) ^ (news_id * 131) ^ (ai_index * 17))` 로 뽑는다. 매매 판정과 **다른 시드 조합**을 써야 "말한 사람이 곧 산 사람" 이 되지 않는다.

## 5. 글은 의견만, 행동은 체결 피드가

글은 *"제노셀 이거 진짜 간다"* 라고만 한다. **샀는지는 말하지 않는다.**

그래서 **말과 행동이 어긋날 수 있다** — 강세로 떠들었는데 현금이 없어 못 산 경우다. 체결 피드와 대조하면 그게 보이고, 그 자체가 읽을거리가 된다.

등장 시각은 기사 등장 후 그 AI 의 `reaction_ticks` 근처다. 체결과 글이 같은 무렵에 뜬다.

## 6. 자료와 계약

### `BoardPost`

```python
@dataclass(frozen=True)
class BoardPlan:
    """글 한 편의 확정된 사실. 문장이 붙기 전 단계다."""
    post_id: int
    news_id: int
    ai_index: int
    author: str
    symbol: str
    bullish: bool        # view_of 결과. 프롬프트에 톤으로만 들어간다
    publish_tick: int
```

```python
@dataclass
class BoardPost:
    plan: BoardPlan
    body: str
    offline: bool = False
```

### 스냅샷에 붙는 것

```json
{ "board": [
    { "post_id": 12, "news_id": 3, "author": "김부장", "symbol": "geno",
      "name": "제노셀", "age_seconds": 24, "body": "제노셀 이거 진짜 간다…",
      "offline": false } ] }
```

`GET /api/state` 에 `board_since` 쿼리가 붙는다. `since`·`trades_since` 와 **같은 방식**이다.

**`bullish` 는 내보내지 않는다.** 글의 톤으로만 드러나야 하고, 플래그로 주면 파싱 한 번에 아홉 명의 판단이 공짜가 된다.

## 7. 실패해도 게임은 멈추지 않는다

`fetch_posts` 는 `fetch_news` 와 같은 실패 경로 다섯을 갖는다 — 키 없음·예외·거절·빈 응답·정상. 어떤 실패든 `fallback.write_posts` 로 떨어지고 `offline: true` 로 표시된다.

## 9. 테스트

**네트워크도 Claude 도 부르지 않는다.** 기존 325개의 성질을 지킨다.

| | 무엇 | 왜 |
|---|---|---|
| 1 | **프롬프트에 통찰력이 없다** | §2 의 핵심. 새면 분석 5회가 죽는다 |
| 2 | 응답에 `bullish` 가 없다 | 파싱 한 번에 판단이 공짜가 되면 안 된다 |
| 3 | 같은 시드가 같은 발언자를 낸다 | 재현 |
| 4 | 발언자 선택이 매매 판정과 다른 시드를 쓴다 | "말한 사람 = 산 사람" 이 되면 안 된다 |
| 5 | 뉴스당 발언자가 4명을 넘지 않는다 | 0명도 정상이다 |
| 6 | 베팅 비율이 높을수록 자주 말한다 | 성격이 드러나는가 |
| 7 | 실패 경로 다섯이 전부 폴백으로 떨어진다 | 게임은 멈추지 않는다 |
| 8 | `board_since` 로 증분만 온다 | |
| 9 | 등장 전 글은 스냅샷에 없다 | 뉴스와 같은 규칙 |
| 10 | 따라잡기에서 Claude 호출이 안 늘어난다 | §3 |

1번과 4번이 이 작업의 중심이다.
